# La Lignée de Valbrume

RPG mobile multi-générationnel, en français, jouable dans le navigateur (un seul fichier HTML, aucune dépendance à installer).

## Jouer

- En ligne : activez GitHub Pages (Settings → Pages → Branch `main`, dossier `/root`), puis ouvrez `https://<votre-pseudo>.github.io/<nom-du-dépôt>/`.
- En local : ouvrez simplement `index.html` dans un navigateur.
- Sur téléphone : ouvrez la page puis « Ajouter à l’écran d’accueil » pour l’installer comme une application.

## Le jeu

- Carte et voyages, avec embuscades et événements de route.
- 3 chapitres dont l’histoire varie selon les Chroniques des lignées précédentes (légendes, âmes errantes, tombes, état du monde, village).
- 4 classes (guerrier, mage, gardien, clerc), compétences débloquées avec l’expérience, résistances simplifiées.
- Combat tour par tour avec mode automatique ; rencontres adaptées au niveau du groupe.
- Lignée : mariage, enfants aux talents révélés en grandissant, héritage des traits, vieillissement, retraite, succession.
- Compagnons uniques qui se lient à la famille, lames à louer à la taverne.
- Carnet de souvenirs pour chaque personnage.
- Arène : duels et paris, entraînement, tournoi.
- Chantiers du village persistants d’une lignée à l’autre.
- Export / import de sauvegarde.

## Sauvegarde

La partie est enregistrée dans le navigateur (localStorage). Utilisez l’export de sauvegarde pour la transférer d’un appareil à l’autre.
